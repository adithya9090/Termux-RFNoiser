# Termux-RFNoiser
Use Your Android Phone To Noise Radio Signals From 88-108 Mhz
Download Termux Apk From F-Droid
Install Termux To Your Phone
In Termux Type These Commands:
pkg update -y
pkg upgrade -y
pkg install git -y
pkg install python3 -y
git clone https://github.com/adithya9090/Termux-RFNoiser.git
cd Termux-RFNoiser
bash rfn
